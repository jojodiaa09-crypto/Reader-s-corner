# Hi, I am  Joudy. I built a website that is a comfortable place for every leader to find the most suitable book for him before buying a book.
THE READER'S CORNER: A cozy place for every reader. It is  my first website, and I am so proud of it.
<br>
I only used HTML and CSS.
<br>
As I love reading books, it was hard for me to choose a book, and I didn't know much information about this book; thus, I came up with the idea for the website to solve this problem for readers.
<br> 
This website is designed to help readers explore book reviews, my favourite books from my point of view, and the best-selling books in the world. Before deciding what to read.
 Features: 
Book review: including Book title, author, publication year, about the book, the main characters, the story, and main themes.
<br>
My favourite books: including Book title, author, publication year, about the book, the main characters, the story, main themes, my personal review, my favourite quotes, and my final thought.
<br>
The best-selling books: same as above
